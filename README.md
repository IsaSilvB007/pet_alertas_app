# 🐾 AmparaPet

> Plataforma multiplataforma desenvolvida para conectar cidadãos, ONGs e protetores independentes no resgate e localização de animais em situação de rua ou abandonados via geolocalização.

## 📱 Sobre o Projeto
O **AmparaPet** foi desenvolvido como projeto acadêmico no curso superior de **Análise e Desenvolvimento de Sistemas (ADS)** da **FATEC Ribeirão Preto**, sob a orientação do Prof. Dr. Rodrigo de Oliveira Plotze. O objetivo principal é facilitar a comunicação e a mobilização rápida para o salvamento e cuidado animal na região.

## 🚀 Funcionalidades Principais
- **Autenticação completa:** Fluxo de Login, Novo Cadastro e Redefinição de Senha.
- **Mapa Interativo (Home Mapa):** Visualização de alertas geolocalizados e barra de pesquisa.
- **Filtros rápidos:** Categorias para ONGs, Avisos e Histórico/Gestão de Alertas.
- **Emissão de Alertas:** Interface dedicada para relatar novos casos de resgate.
- **Menu Lateral (Drawer):** Navegação rápida entre as seções do aplicativo.
- **Perfil do Usuário:** Gestão de dados pessoais com validação de campos e e-mail institucional.
- **Tela Sobre:** Informações detalhadas sobre o objetivo, equipe e dados institucionais.
